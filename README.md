1. Open the individual-work folder in Visual Studio Code.
2. Open index.html using a web browser or Live Server.
3. Select a task from the main menu.
4. Open Developer Tools by pressing F12.
5. Select the Console tab to view the results.
6. For Tasks 7 and 8, enter the requested values in the
   prompt dialogs.
